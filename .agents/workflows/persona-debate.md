# Persona Debate (workflow)

Argue a high-impact, high-ambiguity decision from 2-4 genuinely conflicting perspectives (e.g. security vs. shipping speed) before it's locked in, surfacing the real trade-off instead of prematurely converging. Use for new architecture or cross-cutting convention changes with no clearly-correct answer — disproportionate for small, well-scoped changes.

See `.agents/skills/persona-debate/SKILL.md` for the full instructions.
