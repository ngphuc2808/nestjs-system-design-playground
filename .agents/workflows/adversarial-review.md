# Adversarial Review (workflow)

Deliberately critical review pass over a feature's plan.md or a pre-merge diff, hunting for unhandled edge cases, security-boundary violations, and silently broken contracts. Use before committing to an implementation approach (Plan to Task) or before merging/opening a PR, especially at strict rigor.

See `.agents/skills/adversarial-review/SKILL.md` for the full instructions.
